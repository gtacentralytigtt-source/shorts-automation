Privacy Policy for Shorts Automation

Last updated: September 20, 2026

Overview

Shorts Automation is a desktop application for preparing, processing and publishing short-form video content.

Shorts Automation is currently being privately developed and tested and may be made available to additional users in the future.

Shorts Automation uses YouTube API Services.

Google and YouTube Authorization

Shorts Automation uses Google OAuth 2.0 to request permission from the user before accessing YouTube API Services.

The application only performs YouTube actions for the account and channel authorized by the user.

Depending on the features selected by the user, Shorts Automation may upload videos and related publishing information including titles, descriptions, tags, categories, thumbnails and visibility settings.

Information Accessed and Used

Shorts Automation accesses only the YouTube authorization and API data necessary to provide the features requested by the user.

The application does not request or store the user's Google or YouTube password.

Authentication credentials and OAuth tokens may be stored locally on the user's device so the user does not need to authorize the application every time it is used.

Video Processing and AI Services

Video files and generated project data are primarily processed and stored locally on the user's device.

Some features may send limited content-derived information, such as transcript text or editing context, to third-party AI services when necessary to perform features requested by the user, such as clip selection or metadata generation.

Shorts Automation does not sell Google or YouTube user data.

Data Sharing

Shorts Automation does not sell personal information or YouTube API data to advertisers or unrelated third parties.

Information may be transmitted to Google and YouTube as necessary to perform actions explicitly requested by the authorized user.

Limited information may also be processed by service providers required to provide application functionality.

Data Retention

Local project files, generated metadata and authentication data may remain on the user's device until deleted by the user or by the application as required.

Shorts Automation does not intentionally retain YouTube Authorized Data longer than necessary to provide the requested functionality.

Revoking YouTube Access

Users may revoke Shorts Automation's authorization to access YouTube API Services.

Access may also be revoked through Google's account permissions:

Google Account Permissions

If authorization is revoked, Authorized Data stored pursuant to that authorization will be deleted as soon as reasonably possible and no later than seven calendar days after revocation, as required by YouTube API Services policies.

Data Deletion Requests

Users may request deletion of personal information or Authorized Data associated with Shorts Automation.

During the current private testing phase, deletion requests may be submitted through the Shorts Automation GitHub project.

User Control

Shorts Automation is designed so that YouTube actions are performed only after the user has authorized the application.

Users remain responsible for the content they choose to process and publish through the application.
