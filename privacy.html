Privacy Policy for Shorts Automation

Last updated: September 20, 2026

Overview

Shorts Automation is a personal desktop application used to process short-form video content and upload that content to the application owner's YouTube channel.

Shorts Automation uses YouTube API Services.

Google and YouTube Account Access

Shorts Automation uses Google OAuth 2.0 to request authorization from the user before accessing YouTube API Services.

The application currently requests permission to upload videos to the authorized YouTube account.

The application may use this authorization to upload video files and associated information such as titles, descriptions, tags, categories, visibility settings and thumbnails.

Information Accessed

Shorts Automation only accesses YouTube account information and permissions necessary to perform actions explicitly authorized by the user.

The application does not request access to passwords.

Local Data Storage

Authentication credentials and OAuth tokens may be stored locally on the user's computer so that the user does not need to authorize the application every time it is used.

Video files, generated metadata, thumbnails and application data are also processed and stored locally on the user's computer unless they are uploaded to YouTube at the user's direction.

Data Sharing

Shorts Automation does not sell personal information.

Shorts Automation does not share Google or YouTube user data with advertisers or unrelated third parties.

Data is transmitted to Google and YouTube only as necessary to perform actions requested by the authorized user through YouTube API Services.

Data Retention and Deletion

Locally stored application data remains on the user's computer until the user deletes it.

The user may delete locally stored OAuth credentials and tokens to remove the application's locally stored authorization information.
