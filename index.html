Shorts Automation

Shorts Automation is a desktop application for preparing and publishing short-form video content.

The application can process source video, identify suitable short-form clips, create vertical edits, captions, metadata and thumbnails, and assist with publishing finished content.

YouTube Integration

Shorts Automation uses YouTube API Services to upload videos and related publishing information to the YouTube channel authorized by the user.

YouTube actions are performed only after the user authorizes the application through Google OAuth.

Depending on the features selected by the user, the application may upload videos, titles, descriptions, tags, categories, thumbnails and visibility settings.

Current Availability

Shorts Automation is currently being privately developed and tested.

The application may be made available to additional users in the future.
